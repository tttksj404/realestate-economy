## 1. 상황과 판돈
- 무엇 때문에 시작했나: README의 핵심 가설은 "저가 매물 급증 + 공매 증가 = 경기 침체 시그널". 매물·거래·공매 데이터로 거시경제 상황을 AI가 판단하는 서비스를 만들려 함.
- 왜 중요했나: 본인 서술(2026-11-06)로는 부동산 정책 영향을 사람들이 편하게 볼 수 있게 만들려는 공익적 의도였음. 실제 이용자나 기관의 요구는 없음.
- 그때의 제약: 공공 API 키(data.go.kr, 온비드) 필요, 로컬 LLM 미세조정은 GPU 16GB+ VRAM 가정(README). 기한 미확인.
